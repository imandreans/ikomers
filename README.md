# Ikomers - E-Commerce API

Simple E-Commerce API with FastAPI

## Features
Sign Up: create account.
Log In: Log in with available accout.
Ordered Items: User can see their ordered items.
Purchase Items: User can purchase one and more items.
List products: User can see all the products.
Update Account: User can update their bio.

## Tech Stack
Python 3.13.14 for the programming language
PostgreSQL for the Database
FastAPI for the Framework
JSON Web Token for Authorization
